# 本命天赋 · 在线体验版

直接使用：[打开本命天赋](https://bihu1218.github.io/inner-atlas-demo/)

道家视听样板：[进入云山观势](https://bihu1218.github.io/inner-atlas-demo/?space=dao)

手机或电脑浏览器均可访问，无需安装，也无需登录 GitHub。声音需点击“听见山水”开启。

## 下载保存

需要离线保存时，点击本仓库的 **Code → Download ZIP**，解压后打开 `index.html`，并保留同目录的 `assets` 文件夹。推荐联网使用上面的网页入口；不同浏览器对本地媒体播放的支持可能不同。

## 数据与范围

这是公开的网页成品与媒体发布仓库。个人档案和修习笔记保存在使用者自己的浏览器中，不包含在本仓库，也没有云同步；清除网站数据前请导出备份。

星座用于象征性自我探索。国学内容提供经典阅读与日常练习线索。道家山景为原创生成图像制作的动态影像与视差场景，声景为原创合成音色。
