# 本命天赋 · 在线体验版

[打开本命天赋](https://bihu1218.github.io/inner-atlas-demo/?v=living-spaces-20260907)

把上面的网页链接发给朋友，手机或电脑浏览器直接打开，无需下载或登录 GitHub。

## 三处意境动景

- [儒 · 书院晨光](https://bihu1218.github.io/inner-atlas-demo/?space=ru&view=cinema&v=living-spaces-20260907)：晨光木色、杯口茶烟、庭院水光与轻移树影。
- [道 · 山水云岚](https://bihu1218.github.io/inner-atlas-demo/?space=dao&view=cinema&v=living-spaces-20260907)：山水、流云、湖面折射与竹叶微动。
- [佛 · 莲池晚照](https://bihu1218.github.io/inner-atlas-demo/?space=fo&view=cinema&v=living-spaces-20260907)：金色晚照、荷叶、倒影与灯光。

进入后点击播放按钮开启音乐。全屏右上角提供播放、设置、退出；设置中可选音乐、调音量或关闭风景微动。保留星座银河、每日修习与睡眠陪伴的 15/30/45 分钟定时淡出。

## 音乐与素材

当前曲库包含项目提供的 12 首音乐，按星空、儒、道、佛分类。不是此前的九种合成音色版本。场景使用生成图像与实时局部动画，不是实景拍摄或可自由漫游的完整三维重建；设备不支持时回退原有影像或静态图。

## 记录与隐私

个人档案和笔记保存在使用者当前设备的浏览器中，没有笔记上传或云同步。清理网站数据或换设备前请导出备份。本仓库只包含网页成品和媒体，不包含个人笔记、档案或登录凭据。

源码在独立私有仓库维护；浏览器运行所需的前端成品公开可读。包含 Three.js，其 MIT 许可见 THREE-LICENSE.txt。
