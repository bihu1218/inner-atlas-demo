进入后点击播放按钮开启音乐。全屏右上角提供播放、设置、退出；设置中可选音乐、调音量或关闭风景微动。保留星座银河、每日修习与睡眠陪伴的 15/30/45 分钟定时淡出。

## 音乐与素材

当前曲库包含项目提供的 12 首音乐，按星空、儒、道、佛分类。不是此前的九种合成音色版本。场景使用生成图像与实时局部动画，不是实景拍摄或可自由漫游的完整三维重建；设备不支持时回退原有影像或静态图。

侧边栏第 05 项「东方星图」。输入公历生日和出生时辰，本地生成一张十二星区天赋分布图：中间是主天赋星，十二个区域各配天赋解读和本周可做的起步动作。

底层逻辑完整接入（引擎 iztro，MIT）：十二宫布局、十四主星、主星亮度（对外显示为「势强／势稳／待养」）、辅星（对外显示为搭手星／提携星／才思星／厚积星／奔走星／磨砺星／火花星／留白星）、四化（机会位／发力位／口碑位／磨炼位）、三方四正（对外显示为「联动区」，每区显示给它供能的三个区域，可点击跳转）、身宫（后天发力）。对外零命理词。

- 收款码图片为 `assets/web/ea-pay-qr.jpg`（已放入，自动显示在弹窗里）。
