# 本命天赋 · 在线体验版

直接使用：[打开本命天赋](https://bihu1218.github.io/inner-atlas-demo/)。手机或电脑浏览器均可打开，无需下载或登录 GitHub。

## 三处修习空间

- [儒 · 琴书修身](https://bihu1218.github.io/inner-atlas-demo/?space=ru)：书院晨光动态影像，搭配古琴风格配乐与庭院环境声。
- [道 · 云山观势](https://bihu1218.github.io/inner-atlas-demo/?space=dao)：云山水面动态影像，搭配箫风格配乐与溪水声。
- [佛 · 莲池观心](https://bihu1218.github.io/inner-atlas-demo/?space=fo)：莲池寺院动态影像，搭配钟磬、木鱼风格音色与池畔环境声。

进入后点击「播放……」开启音乐。音乐和环境声有独立音量。播放过程中切换空间会更换配乐；主动暂停后保持暂停。无法听见时，可打开「听不到声音？」检查媒体音量、蓝牙/投屏输出或重新播放。

首页还有 Gamma 40 Hz 节律与星海回声的试听选择。每日修习提供读经典、做练习、留心得的入口。

## 下载与记录

需要保存网页文件：在本仓库点击 **Code → Download ZIP**，解压后打开 `index.html`，并保留整个 `assets` 文件夹。推荐使用在线入口；浏览器对本地文件的媒体支持可能不同。

个人档案和笔记保存在使用者自己的浏览器中，没有云同步。清理网站数据前请导出备份。公开仓库仅包含网页成品和媒体，不包含私密档案、笔记或登录凭据；浏览器代码公开可读。

## 素材说明

场景使用原创生成图像制作循环动态影像，并非实拍。配乐是原创合成音色，不是名家录音或经文唱诵。Gamma 选项为 40 Hz 幅度调制的原创音景，不是临床疗法。星座用于象征性探索，经典提供日常阅读与实践线索。
