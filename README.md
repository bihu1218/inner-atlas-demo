# 本命天赋 · 在线体验版

**直接打开，无需下载或登录 GitHub：** [本命天赋](https://bihu1218.github.io/inner-atlas-demo/)

手机首页提供清楚的「今日修习」与「星座探索」入口。读一句经典、做一次练习、留一句心得；个人记录保存在自己的浏览器中。

**声音：**点击「试听 Gamma 声景」，或从「选声景」中选择 Gamma 40 Hz 节律、星海回声，调节音量，也可以先听三分钟再进入修习。声音需主动点击，不会自动播放。

**道家视听样板：**[进入云山观势](https://bihu1218.github.io/inner-atlas-demo/?space=dao)，点击「听见山水」开启独立的山水声景。

## 下载保存

在本仓库点击 **Code → Download ZIP**，解压后打开 `index.html`，保留同目录整个 `assets` 文件夹。推荐使用上面的在线入口；不同浏览器对本地文件与媒体播放的支持可能不同。

## 数据与素材

这是公开的网页成品与媒体仓库，浏览器代码可供查看。不包含私人档案、笔记、备份和登录凭据；个人记录没有云同步，清除浏览器网站数据前请导出备份。

星座用于象征性自我探索。国学内容提供经典阅读与日常练习线索。道家山景为原创生成图像制作的动态影像与视差场景，声景为原创合成音色。Gamma 选项为加入 40 Hz 幅度调制的原创音景，不是临床疗法。
